# 离散

[← 数学](../README.md)

逻辑、集合、证明、图论、组合。计算机里大多数「对不对」的说法，都落在这套语言上。

## 为什么要学

读文档和源码时会碰到：充要条件、集合的交和并、归纳法证明一个循环是对的、用图描述页面跳转或依赖关系。这些词如果只靠中文感觉去猜，后面的算法和数据库会越读越虚。

它也是写单测时的底：边界、空集、互斥、覆盖，都是从这里来的。

## 建议顺序

1. **逻辑** — 与或非、蕴含、真值表。先分清「如果 A 那么 B」和「A 当且仅当 B」。
2. **集合** — 属于、子集、交并补、笛卡儿积。关系是集合的集合，函数是一种关系。
3. **证明** — 直接证、反证、数学归纳。先会跟着一个归纳证明走完，再自己写一个小的，比如「前 n 个数的和」。
4. **图论** — 点、边、路径、环、树、度。先认图，算法放在 [03](../../03-data-structures-algorithms/README.md) 里做。
5. **组合** — 加法原理、乘法原理、排列组合。用来估计一个操作有多少种可能，给复杂度分析垫底。

## 书和课

- 《离散数学及其应用》（Rosen）挑逻辑、集合、归纳、图这几章，不必通读
- [CS 自学指南](https://csdiy.wiki/) 里的离散数学课，以前几周为主

做的时候让 AI 写一个真值表页面，或者一个能点的小图：加一条边，看路径有没有变。证明不要只看 AI 写完，自己合上屏幕复述归纳的两步：基础、从 n 到 n+1。
