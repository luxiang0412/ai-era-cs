# 概率

[← 数学](../README.md)

概率、分布、贝叶斯、信息论。先建立「不确定的事怎么量化」，再碰模型。

## 为什么要学

接口的超时、缓存命中率、A/B 实验、模型输出的下一个词，都不是一个确定的数。概率给的是：在什么前提下，这件事有多常见。信息论里的熵和交叉熵，是后面看损失函数时会碰到的名字。

## 建议顺序

1. **概率** — 样本空间、事件、条件概率。先把 P(A|B) 读成「已经知道 B 时，A 的概率」，不要和 P(B|A) 混。
2. **分布** — 伯努利、二项、正态。知道一个分布在描述「重复的独立试验」还是「聚在均值附近的连续量」。期望和方差是它的两个摘要。
3. **贝叶斯** — 用新的观察更新原来的判断。公式先放一边，先会说：先验、似然、后验各是哪一句人话。
4. **信息论** — 熵是「平均还要多少信息才能确定结果」。交叉熵衡量两个分布差多远，分类损失常用它。先要这个图像，推导以后再说。

## 书和课

- 《概率导论》（Blitzstein）或任何一本讲条件概率讲得慢的书，前几章
- 信息论入门可以只读一篇把熵讲成「惊讶程度」的笔记，再在 [动手学深度学习](https://zh.d2l.ai/) 里看到交叉熵时折回来

demo：一个硬币，连续投，频率慢慢靠近概率；一个小的贝叶斯更新，滑块改「检查呈阳性」的可靠性，看后验怎么动。
