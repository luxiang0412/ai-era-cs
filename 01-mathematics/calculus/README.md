# 微积分

[← 数学](../README.md)

导数、梯度、链式法则。这一目录先够用到 [神经网络](../../25-deep-learning-generative-ai/README.md) 的反向传播，不展开积分技巧。

## 为什么要学

训练模型是在调一堆数，让损失变小。损失往哪边变小，就是梯度的反方向。层数一多，梯度要用链式法则一层层传回去。没有这个图像，反向传播只是一段会背的代码。

动画里的缓动、曲线的切线，也是同一个导数。

## 建议顺序

1. **导数** — 变化率。函数图像上某一点的切线斜率。先会看 f(x) 变大时斜率是正是负，再记几个常见函数的导数。
2. **梯度** — 多元函数。每个自变量一个偏导，拼成一个向量，指向增加最快的方向。梯度下降是往反方向走一小步。
3. **链式法则** — 函数套函数时，变化率相乘。`y` 依赖 `u`，`u` 依赖 `x`，则 dy/dx = dy/du · du/dx。神经网络的每一层就是这样套起来的。
