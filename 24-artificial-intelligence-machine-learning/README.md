# 24 人工智能与机器学习

[← 回到路线](../README.md)

搜索、规划、知识表示、经典机器学习、模型评估、信息检索与推荐、MLOps。完整子类见 [知识地图](../knowledge-map.md)。目标是知道一个模型在拟合什么、错的时候错在哪一层，不是把训练框架用熟。

## 为什么要学

用模型做产品的时候，要能判断：是数据不够，是任务根本不该交给生成模型，还是上下文里没给够事实。很多问题用规则、搜索或一个逻辑回归就能解决，比上大模型更便宜、更可解释。数学上的依赖已经记在 [微积分](../01-mathematics/calculus/README.md) 和 [概率](../01-mathematics/probability/README.md) 里，写到对应小节就回去。

## 建议顺序

1. **经典 AI** — 搜索与问题求解、启发式搜索、规划。A* 在图上找路，和 [03 的图算法](../03-data-structures-algorithms/README.md) 是同一件事加了一个估价。
2. **知识表示** — 逻辑推理、规则引擎、本体与知识图谱（RDF / OWL）。知道「把知识写成规则」和「从数据里学出来」各自的代价。
3. **机器学习基础** — 用数据拟合一个函数。训练集、损失、过拟合（记住了训练数据，换一批就差）。先做一个线性回归，看见损失往下走。
4. **监督与无监督** — 逻辑回归、决策树、随机森林、SVM、聚类、降维。每个只要能说出它在画什么样的边界。
5. **特征工程与集成学习** — 表格数据上，好特征加梯度提升树往往比深度网络稳。
6. **模型评估** — 训练 / 验证 / 测试划分、交叉验证、准确率和召回率的取舍。指标选错，后面全白做。
7. **强化学习** — 智能体、环境、奖励。先懂这个框架，[25](../25-deep-learning-generative-ai/README.md) 和 [26](../26-llm-agent-systems/README.md) 里的 RLHF 才看得懂。
8. **信息检索与推荐** — BM25、Learning to Rank、召回加排序的两段式推荐。搜索框和信息流背后都是它，也是 [26 里 RAG](../26-llm-agent-systems/README.md) 的检索那一半。
9. **MLOps** — 数据和模型的版本、训练流水线、上线后的漂移监控。

## 书和课

- Russell, Norvig《人工智能：一种现代方法》（AIMA），当经典 AI 的字典
- 周志华《机器学习》，或吴恩达的 Machine Learning 课
- Sutton, Barto《强化学习》，只读前几章的框架
