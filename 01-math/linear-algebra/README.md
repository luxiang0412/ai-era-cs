# 线性代数

[← 数学](../README.md)

向量、矩阵、变换、特征值、SVD。这里先要几何图像，公式是图像的压缩。

## 为什么要学

CSS 变换、Canvas、相机、推荐系统里的向量、神经网络的一层，底下都是同一件事：一个列表的数被一个表乘了一次，变成另一个列表。把矩阵理解成「表格」会在乘法不满足交换律的时候卡住。把它理解成「空间的变换」，顺序就说得通了。

## 建议顺序

1. **向量** — 箭头，有方向有长度。加法是首尾相接，数乘是拉长或反向。坐标只是在一组基下的写法。
2. **矩阵** — 把一个向量变成另一个向量的规则，写成一张表。先看 2×2，足够看见旋转、缩放、剪切。
3. **变换** — 矩阵乘法是变换的复合，顺序不能随便换。逆变换是把它变回去。线性组合和张成用来回答「这些向量能拼出哪些位置」。
4. **特征值** — 有些方向被变换之后还留在原方向上，只是被拉长。那个方向是特征向量，拉长的倍数是特征值。
5. **SVD** — 把一个变换拆成旋转、沿坐标轴缩放、再旋转。先知道它在说「任何线性变换都能这么拆」，应用（降维、压缩）放后面。
