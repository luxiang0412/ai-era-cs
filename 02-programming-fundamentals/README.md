# 02 编程基础与计算模型

[← 回到路线](../README.md)

类型、控制流、函数与作用域、内存模型、错误处理、I/O、并发基础、编程范式。完整子类见 [知识地图](../knowledge-map.md)。

## 为什么要学

天天写代码不等于把这些讲得清。值语义和引用语义分不清，就会有「改了一个对象，另一个地方也变了」；不懂作用域和闭包，就会有循环里的回调全拿到最后一个值。这些是后面所有科类的共同语言。

## 建议顺序

1. **类型与表达式** — 变量、常量、数据类型、运算符。知道每一个值在内存里大概长什么样。
2. **控制流与函数** — 条件、循环、函数、作用域、闭包、模块与包。
3. **内存模型** — 指针、引用、值语义与引用语义。和 [06 系统级编程](../06-systems-programming/README.md) 的栈与堆对着看。
4. **错误处理** — 异常、返回值、`Result`。错误是往上抛还是就地处理，是设计决定。
5. **I/O 与网络** — 文件、流、Socket 的最小用法。细节留给 [08](../08-computer-networks/README.md)。
6. **并发与异步** — 线程、回调、Promise、async/await。前端的事件循环在 [19](../19-web-client/README.md) 里细讲。
7. **编程范式** — 面向过程、面向对象、函数式、泛型。同一个小问题用三种范式各写一遍，再比较。
8. **调试与可读性** — 程序一步步怎么执行；命名、注释、格式。
