# 25 深度学习与生成式 AI

[← 回到路线](../README.md)

神经网络、反向传播、CNN、RNN、Attention、Transformer、生成模型、训练与推理优化。完整子类见 [知识地图](../knowledge-map.md)。

## 为什么要学

LLM 是这一层上面的一个特例。不懂网络怎么训练，就只能把模型当黑盒调参数。这一节要能回答：这一层在做什么变换，梯度从哪里传回来，为什么大了以后要量化、要分布式。

## 建议顺序

1. **神经网络** — 一层是一次线性变换加一个非线性。没有非线性，很多层叠起来还是一次线性变换。和 [矩阵是变换](../01-mathematics/linear-algebra/README.md) 是同一幅图。
2. **反向传播** — 损失对每一层参数的梯度，用链式法则从输出传回输入。先手算一个两层、每个层一个数的例子，再看框架里的自动求导。
3. **训练细节** — 激活函数、损失函数、优化器、梯度消失与爆炸、正则化。每一个都是在修上一个出的问题。
4. **CNN 与 RNN** — 卷积共享权重看局部，循环网络带着状态往后走。知道它们为什么被 Transformer 替掉了大部分场景。
5. **Transformer** — 自注意力：每个位置去看序列里其他位置，加权汇总。位置编码补上「顺序」。先能指着一个小句子说出注意力权重在看谁。
6. **生成模型** — 自编码器、VAE、GAN、Diffusion。各自怎么从噪声或压缩表示里还原出样本。
7. **多模态** — 图像、语音、文本对齐到同一个空间。
8. **规模化** — 微调、分布式训练、量化、推理优化、评估与对齐。和 [22 并行计算](../22-parallel-high-performance-computing/README.md) 接上。
