# 03 计算机组成

[← 回到路线](../README.md)

二进制、门、CPU、指令、流水线、缓存、内存层次。这一层回答：高级语言的一行，到了机器上是什么在动。

## 为什么要学

不自己做芯片，也需要这张图。性能问题经常是「数据没在缓存里」而不是「JS 写得丑」。看汇编、看 `perf`、理解为什么按行遍历二维数组和按列差很远，都靠这一层。

Nand2Tetris 的走法适合建立图像：从与非门搭到能跑程序的机器。不必先背完所有术语。

## 建议顺序

1. **二进制编码** — 无符号、补码、十六进制。负数为什么用补码：加法电路可以一套用到底。浮点先知道「它是科学计数法」，细节跟 [04](../04-system/README.md) 一起看。
2. **逻辑门** — 与或非、与非。组合电路没有记忆，输出只跟当前输入有关。
3. **CPU** — 先有时钟和寄存器。算术逻辑单元算一步，寄存器记住结果。控制单元决定下一步干什么。
4. **指令集** — 指令是编码过的操作：取数、算、跳转。写几行汇编，看它和 `if`、循环的对应关系。
5. **流水线** — 把一条指令拆成几级，重叠着做。冒险（下一条要用上一条还没写完的结果）是它的代价。
6. **缓存** — 局部性：刚用过的、旁边的，很可能再被用到。命中和缺失比「缓存就是更快的内存」这句话具体。
7. **内存层次** — 寄存器、缓存、内存、磁盘，越远越大越慢。写程序时的数据布局，是在跟这个层次打交道。
