# 03 数据结构与算法

[← 回到路线](../README.md)

数组、链表、栈、队列、哈希、树、堆、图、排序、二分、递归、动态规划、贪心，以及复杂度。目标是读代码时能判断「这里为什么用这个」，而不是默写模板。完整子类见 [知识地图](../knowledge-map.md)。

## 为什么要学

业务代码里天天在选：这个列表要不要改成 Map，这个查找能不能二分，这个递归会不会把栈打爆。前端还会碰到虚拟列表、树形 JSON、路由匹配、diff。结构选错的时候，性能问题看起来像框架的锅。

## 建议顺序

复杂度放在最后集中写，是因为前面每一节都在用它。看的时候随时问一句：再加一倍数据，这里大概慢多少。证明留到最后。

1. **数组与链表** — 连续内存和指针跳跃。按下标取是数组的强项，中间插入是链表的理由，但现代机器上数组往往更快，这个反差要自己量一次。
2. **栈与队列** — 后进先出、先进先出。函数调用栈、撤销、广度优先搜索，都是这两个的应用。
3. **哈希** — 用空间换平均情况下接近常数的查找。要知道冲突、扩容，以及「最坏可以退化成一条链」。
4. **树** — 先二叉树和二叉搜索树。平衡为什么重要，先有概念，红黑树的旋转细节可以后补。
5. **堆** — 随时取出最大或最小。优先队列、定时器、Top K。
6. **图** — 邻接表。先 BFS 和 DFS，再最短路。图论语言在 [离散](../01-mathematics/discrete/README.md)。
7. **排序** — 先会用，再知道比较排序的下界，以及为什么有时候可以不比较（计数、基数）。
8. **二分** — 不只是在有序数组里找数。任何「一半肯定可以丢掉」的单调问题都可以二分。边界要自己写错几次。
9. **递归** — 问题缩小一号，加上会停的基础情形。先画调用树，再谈优化。
10. **动态规划** — 递归里的重复子问题，用表记下来。先从「爬楼梯」这种一维的做起，再看二维。
11. **贪心** — 每一步都选当前看起来最好的，而且能证明不会后悔。和动态规划的差别是：贪心不保留其他选择。
12. **复杂度分析** — 大 O 在说增长趋势，不是精确耗时。补上均摊（比如动态数组扩容）和递归式。把前面每个结构的操作成本写回自己的笔记。

## 书和课

- Sedgewick《算法（第 4 版）》，[algs4.cs.princeton.edu](https://algs4.cs.princeton.edu/home/)
- Princeton 的 Algorithms 课（Coursera 上的两部分），和这本书是一套
- 想用 JavaScript 写的话，对照书里的 Java 自己译一小段，不要换一本完全不同的教材同时看

每一节让 AI 写一个能单步的可视化：数组和链表插入、堆的上浮、二分缩小区间、背包问题填表。自测是能在纸上画出一小步，并说出错了会变成什么样。
