# 13 AI

[← 回到路线](../README.md)

机器学习基础、神经网络、反向传播、Transformer、LLM、Agent。目标是知道一个模型在拟合什么、错的时候错在哪一层，不是把训练框架用熟。

## 为什么要学

用模型做产品的时候，要能判断：是数据不够，是任务根本不该交给生成模型，还是上下文里没给够事实。会调 API 和会看它为什么胡说，是两件事。数学上的依赖已经记在 [微积分](../01-math/calculus/README.md) 和 [概率](../01-math/probability/README.md) 里，写到对应小节就回去。

## 建议顺序

1. **机器学习基础** — 用数据拟合一个函数。训练集、损失、过拟合（记住了训练数据，换一批就差）。先做一个线性回归，看见损失往下走。
2. **神经网络** — 一层是一次线性变换加一个非线性。没有非线性，很多层叠起来还是一次线性变换。和 [矩阵是变换](../01-math/linear-algebra/README.md) 是同一幅图。
3. **反向传播** — 损失对每一层参数的梯度，用链式法则从输出传回输入。先手算一个两层、每个层一个数的例子，再看框架里的自动求导。
4. **Transformer** — 自注意力：每个位置去看序列里其他位置，加权汇总。位置编码补上「顺序」。先能指着一个小句子说出注意力权重在看谁。
5. **LLM** — 训练目标多半是预测下一个 token。采样温度改变的是「有多愿意选不那么高的概率」。上下文窗口是它这一次能看见的全部。它不是在数据库里查询，除非你另外接了工具。
6. **Agent 原理** — 一个循环：模型产出要调用的工具和参数，程序真的去调用，把结果塞回上下文，再问模型。它会错，是因为某一步的观察是错的、工具描述是糊的，或者循环没有停的条件。先把这个循环画出来，再谈框架。

- 3Blue1Brown 的神经网络系列，看反向传播的图像
- Transformer 先读一篇带小例子的讲解（例如 “The Illustrated Transformer”），再决定要不要上 Stanford CS224n
