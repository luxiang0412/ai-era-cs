# 04 计算理论

[← 回到路线](../README.md)

自动机、正则语言、上下文无关文法、图灵机、可计算性、复杂性、P 与 NP、形式化验证基础。完整子类见 [知识地图](../knowledge-map.md)。

## 为什么要学

正则表达式为什么匹配不了嵌套括号，状态机为什么是写 UI 和协议最稳的方式，为什么有些问题再怎么优化也只能近似，这一科给出答案。它也是 [11 编译器](../11-programming-languages-compilers/README.md) 的前置：词法分析就是有限自动机，语法分析就是上下文无关文法。

## 建议顺序

1. **有限状态机** — 状态、输入、转移。先拿 TCP 的状态图或一个表单的状态练手，见 [TCP](../08-computer-networks/tcp/README.md)。
2. **正则语言** — 正则表达式和有限自动机是一回事。知道它能表达什么、不能表达什么。
3. **上下文无关文法** — 能描述嵌套。JSON、HTML、编程语言的语法都在这一层。
4. **图灵机与可计算性** — 什么是「能算」。停机问题说明有些事任何程序都判断不了。
5. **复杂性** — P、NP、NP 完全、归约。遇到问题时先问一句：它是不是已知的难题换了个名字。
6. **形式化验证** — 用逻辑证明程序满足规格。先知道它在哪些场景值回票价。
