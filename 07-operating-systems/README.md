# 07 操作系统

[← 回到路线](../README.md)

进程和线程、调度、锁、内存、文件、I/O、终端、容器。内核是资源的分配者：CPU 时间、内存、磁盘、设备。完整子类见 [知识地图](../knowledge-map.md)。

## 为什么要学

服务挂了、请求变慢、容器和宿主机看到的进程不一样、终端里颜色乱了，都在这一层。前端同学会特别容易在「终端和 PTY」这里豁然开朗：为什么 SSH 进去有个 shell，为什么 `docker logs` 和直接跑不是一回事，为什么有的程序检测到不是终端就不着色。

## 建议顺序

1. **进程与线程** — 进程是资源的边界，有自己的地址空间。线程共享这个地址空间，各自有栈。先分清这两个词，再谈并发。
2. **调度** — 很多进程轮流用少量 CPU。时间片、优先级、一个进程在等 I/O 时把 CPU 让出去。公平和吞吐经常打架。
3. **并发与锁** — 共享数据时，交错执行会带来竞态。锁、条件变量。死锁的四个条件先能背出来，再在自己的例子里认。
4. **内存管理** — 从内核的角度看虚拟内存：页框、分配、回收、换出。和 [06](../06-systems-programming/README.md) 的虚拟内存对着读。
5. **文件系统** — 文件是字节序列，目录是特殊的文件。inode 记住「数据在哪些块上」，文件名只是目录里的一个条目。硬链接由此说得通。
6. **I/O** — 设备比 CPU 慢几个数量级。阻塞、非阻塞、多路复用。缓冲区是为了少打扰磁盘和网卡。
7. **终端和 PTY** — 终端是一种字符设备，有行规程（回显、退格）。伪终端成对出现：一边给程序当终端，一边给你的程序读写。SSH、终端模拟器、`script`，都在用它。
8. **容器** — 进程加上隔离：命名空间让它看见一套自己的 PID、网络、文件系统，cgroup 限制它能用多少 CPU 和内存。它不是虚拟机。
