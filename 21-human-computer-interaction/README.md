# 21 人机交互与交互设计

[← 回到路线](../README.md)

认知心理学基础、信息架构、交互设计原则、视觉与动效、可用性、无障碍、用户研究与原型、多模态与语音、Human-AI Interaction。完整子类见 [知识地图](../knowledge-map.md)。

## 为什么要学

写前端就是在做交互，只是常常凭感觉。这一科给感觉找依据：为什么这个按钮没人点，为什么用户看不懂这条报错。AI 产品又多了新问题：输出不确定、要等很久、会出错，界面要怎么让人信得过、改得动。

## 建议顺序

1. **人的模型** — 认知负荷、注意力、心智模型。设计是在跟这些限制打交道。
2. **信息架构** — 东西放在哪、叫什么名字、从哪里能找到。
3. **交互原则** — 可见性、反馈、约束、一致性。
4. **视觉与动效** — 排版、层级、对比、动效的作用。
5. **可用性与无障碍** — 键盘可达、读屏、对比度。WCAG 是底线。
6. **用户研究** — 访谈、原型、可用性测试。五个人就能发现大部分问题。
7. **多模态与人机协作** — 语音、多模态、Human-in-the-loop。
8. **AI 产品交互** — 流式输出、可撤销、展示依据、让用户纠正。接 [26](../26-llm-agent-systems/README.md)。
